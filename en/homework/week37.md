# Assignment 37

> **Definition 5.6.1** (Numeral Codes) <br>There are many numeral codes in daily life; they are "identity numbers" that people assign to objects according to a certain standard based on actual needs, and each part of the digits stands for specific information. The citizen identity number consists of $18$ digits: an address code, a birth-date code, a sequence code and a check code; the $17$th digit is odd for male and even for female; the check code is computed from the first $17$ digits and may be $0\sim10$, written as the Roman numeral X when it is $10$.
>
> **Definition 5.6.2** (Designing a Coding Scheme) <br>To design a coding scheme, first decide which information it must contain (such as grade, class, sequence number, and gender), then specify a fixed number of digits and an order for each part; when the coding range is expanded (whole class, whole school, whole city), the scheme must add corresponding digits so that there is no repetition.

### Exercise 175

(Lesson: Getting to Know Numeral Codes — Share Your Thoughts) How is the citizen identity number compiled? What do the digits on the ID card mean?

### Solution to Exercise 175

By **Definition 5.6.1** (Numeral Codes), in the $18$-digit number: the first $6$ digits are the address code (province, city, county), the next $8$ digits are the birth-date code (year, month, day), the sequence code (digits $15\sim17$, with the $17$th odd for male and even for female), and the last $1$ digit is the check code. $\blacksquare$

### Exercise 176

(Lesson: Getting to Know Numeral Codes — Think It Through, Problem 1) Will a pair of twins have the same citizen identity number? Why?

### Solution to Exercise 176

No. Although their birth dates are the same, the sequence codes differ (people born at the same address on the same year-month-day are numbered in order, and the $17$th digit can also distinguish gender), so the twins' identity numbers are different. $\blacksquare$

### Exercise 177

(Lesson: Getting to Know Numeral Codes — Think It Through, Problem 2) Look at codes such as ID card numbers and postal codes; what features do they have?

### Solution to Exercise 177

By **Definition 5.6.1** (Numeral Codes), the features are: each part has a fixed number of digits and stands for specific information from left to right; the digits are arranged according to a uniform standard and can uniquely distinguish each object; and there is a check digit to verify whether the number is correct. $\blacksquare$

### Exercise 178

(Lesson: Compiling Student Numbers — Discuss) Discuss in groups: what information should a student number contain? How can it be designed?

### Solution to Exercise 178

By **Definition 5.6.2** (Designing a Coding Scheme), a student number may contain the enrollment year (such as $2026$), grade, class (two digits), in-class sequence number (two digits), and a gender code may be added. For example, $20260302152$: enrolled in $2026$, grade $3$, class $2$, number $15$, female. $\blacksquare$

### Exercise 181

(Lesson: Mini Lecture) What other numeral codes are there in daily life? What is the difference between the first-generation ID card numbering and the second generation?

### Solution to Exercise 181

In daily life there are also postal codes, license plate numbers, house numbers, student numbers, product barcodes, and so on. The first-generation ID card numbering has only $15$ digits, which, compared with the second-generation $18$ digits, is short two digits of the year code (for example, $99$ is written as $1999$) and one digit of check code. A book ISBN is also a code, containing a group code, a publisher code, a title number and a check code. $\blacksquare$
