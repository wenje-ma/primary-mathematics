# 作业 79

> **定义 10.2.1** (因数与倍数) <br>在整数除法中, 如果商是整数且没有余数 (余数为 $0$), 就说除数是被除数的因数 (也称约数), 被除数是除数的倍数. 因数和倍数是相互依存的, 研究因数和倍数时所说的数一般指不包括 $0$ 的自然数.
> 
> **定义 10.2.2** (因数与倍数的特点) <br>一个数的因数的个数是有限的, 最小因数是 $1$, 最大因数是它本身; 一个数的倍数的个数是无限的, 最小倍数是它本身, 没有最大倍数.
> 
> **定义 10.2.3** (偶数与奇数) <br>整数中, 是 $2$ 的倍数的数叫作偶数 ($0$ 也是偶数), 不是 $2$ 的倍数的数叫作奇数.
> 
> **定义 10.2.4** (2, 5, 3 的倍数的特征) <br>个位上是 $0,2,4,6,8$ 的数都是 $2$ 的倍数; 个位上是 $0$ 或 $5$ 的数都是 $5$ 的倍数; 一个数各位上的数的和是 $3$ 的倍数, 这个数就是 $3$ 的倍数.
> 
> **定义 10.2.5** (质数与合数) <br>一个数, 如果只有 $1$ 和它本身两个因数, 叫作质数 (素数); 如果除了 $1$ 和它本身还有别的因数, 叫作合数. $1$ 既不是质数, 也不是合数.

### 练习七

(课时 因数和倍数的认识 做一做) 下面 $4$ 组数中, 谁是谁的因数? 谁是谁的倍数? $4$ 和 $24$, $26$ 和 $13$, $75$ 和 $25$, $81$ 和 $9$.

### 解答 练习七

由**定义 10.2.1** (因数与倍数): $24\div4=6$, 所以 $4$ 是 $24$ 的因数, $24$ 是 $4$ 的倍数; $26\div13=2$, $13$ 是 $26$ 的因数, $26$ 是 $13$ 的倍数; $75\div25=3$, $25$ 是 $75$ 的因数, $75$ 是 $25$ 的倍数; $81\div9=9$, $9$ 是 $81$ 的因数, $81$ 是 $9$ 的倍数. $\blacksquare$

(课时 质数和合数 练习四 第 7 题) 探索 $6$ 的倍数的特征, 并记录你探索的过程和结果.

### 解答 练习三十六

由**定义 10.2.4** (2, 5, 3 的倍数的特征), 列举 $6,12,18,24,30,\cdots$ 观察发现: $6$ 的倍数同时是 $2$ 的倍数 (个位是偶数) 和 $3$ 的倍数 (各位数的和是 $3$ 的倍数), 即既是 $2$ 又是 $3$ 的倍数的数就是 $6$ 的倍数. $\blacksquare$
