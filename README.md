# Primary Mathematics (Elementary, Grades 1–6)

> 105 weeks of lesson notes and fully worked exercises covering the complete PEP (People's Education Press) elementary mathematics curriculum (grades 1–6, twelve volumes), with R-generated teaching figures and a complete English translation.

The repository formalizes the entire PEP elementary series (人教版小学数学) into a definition-first reference plus weekly solved exercise sets, transcribed against the twelve scanned textbook volumes in `textbooks/` (named `1.1.pdf` – `6.2.pdf` = grade 1 vol. 1 through grade 6 vol. 2).

## Repository structure

```
primary-mathematics/
├── notes.md                  # Chinese notes, all 12 volumes (1503 lines)
├── en/
│   ├── notes.md              # Complete English translation (1503 lines, aligned)
│   └── homework/
│       └── week1.md … week105.md
├── homework/
│   └── week1.md … week105.md
├── codes/
│   └── week*.R               # 22 R scripts that generate the figures
├── figures/
│   └── weekNN-k.svg / .pdf   # 22 figure pairs (SVG + PDF)
└── textbooks/
    └── 1.1.pdf … 6.2.pdf     # 12 textbook scans (+ _ocr copies)
```

## The notes

`notes.md` is a single file organized by **grade/volume → unit → section**, giving every concept a numbered definition (基数/序数 counting, composition and decomposition of numbers, operation laws, perimeter and area formulas, etc.) — 1,503 lines in both languages. Only definitions and basic facts live here; worked examples are all in `homework/`.

## The homework

Each `homework/weekN.md` follows the series-wide format:

1. **Toolbox** — a blockquote listing the relevant definitions/basic facts;
2. **Exercises** — the week's problems;
3. **Solutions** — complete worked solutions ending with `$\blacksquare$`, cross-referencing the numbered definitions.

105 weeks in each language. The final weeks (e.g. `week105.md`) combine negative numbers, equations and geometry formulas into comprehensive practice.

## The figures

22 teaching figures (e.g. the unfolded lateral surface of a cylinder) are generated by R scripts in `codes/` using `svglite`/`cairo_pdf`, with one SVG + PDF pair per figure in `figures/`. Scripts are run manually; there is no build automation.

## Bilingual layout

- Root `notes.md` and `homework/` — authoritative Chinese version.
- `en/` — complete English translation, line-count-identical with the Chinese originals.
